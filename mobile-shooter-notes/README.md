# 射擊手遊研究筆記：CODM 與競品

台灣市場的射擊手遊研究，重點是《Call of Duty: Mobile》（Garena 版）和它的競品：PUBG MOBILE、Free Fire、三角洲行動、荒野行動、暗區突圍。內容包含市場數據、評估框架、11 個商業案例的解題骨架、內購拆解、網路聲量，以及 9 份 Sensor Tower 報告的重點數字。資料整理到 2026 年 10 月。
